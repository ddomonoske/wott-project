\section{Notation, Units, and Parameters}
\label{sec:notation}

\Cref{tab:notation} lists every symbol used in this document, its meaning, its
SI unit, its default or typical value where one exists, and the corresponding
function, class, or entity attribute in the implementation. Derivations
throughout this document use SI units exclusively; the single exception is
velocity as reported to the user, which is converted to
\si{\kilo\metre\per\hour} for display only (\cref{sec:sim-outputs}) and is never
used in that form internally.
